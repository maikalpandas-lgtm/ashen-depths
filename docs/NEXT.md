## Долги, о которых юзер не просил, но они реальные

### Финал забега — самое заметное

Спуск **бесконечен**, момента «я победил» нет. В `ROADMAP.md` это
`Trailer floor / curse altar full`. Пока игра не кончается, демо честно
описывается как «играется на сколько хватит» (так и написано в
`build/win_pack/КАК_ИГРАТЬ.txt`).

### Баланс: Витязь слишком крепок

Замерено: враги наносят ровно столько, сколько заявляют (68 заявлено → 68
потеряно при нулевой броне). Копи не кусаются не из-за бага, а потому что у
Витязя 82 HP и колода почти сплошь броня. Предложение, которое юзер пока не
подтвердил: убрать у него один `Заслон` из четырёх защитных карт.

### 128 МБ бинарников в git

`dist/` весит 128 МБ, `.git` — 288 МБ, GitHub ругается на каждый push.
`build/` уже в `.gitignore`, а `dist/` — нет. Правильно: перенести в Releases
и добавить в `.gitignore`. **Спросить перед удалением** — это чужие сборки.

### Нет двух эмбиентов

`amb_cave.ogg` и `amb_nav.ogg` (см. `docs/AUDIO_TODO.md`). Лес озвучен
полностью. Без них в копях и Нави тишина между музыкальными петлями — код
готов, файлов нет.

### Перспективный сдвиг билбордов

Юзер спрашивал, почему крайний моб «наклонён». Померено: поворот узлов и
спрайтов **ровно ноль**. Это перспектива плоского билборда у края кадра при
FOV 58–72°. Не баг; лечится только сужением угла, но тогда стая не влезает.
Если снова спросит — не искать баг заново, а обсуждать компромисс по FOV.

### Мелочь

- `_hover_enemy()` зовётся трижды за кадр из разных мест — можно кэшировать
- viewmodel `no_depth_test` глушится `material_override`, замаскировано
  `PUSH_LIMIT`; правильное лечение — вариант шейдера с `depth_test_disabled`

## Как проверять (это важнее списка задач)

**Запрет на запуск игры СНЯТ** (25.07.2026). Проверять визуал самому:

```bash
tools/fight.sh --forest --floor 4 --hero volhv   # сразу в бой, минуя меню
python3 tools/game.py shot --name check          # кадр → shots/auto/
```

Кадр читать через `Read` и **мерить по нему**, а не описывать словами. За эту
сессию так были найдены: обрезанное «4×» вместо «4×2», подписи на лапах,
веер колоды под кнопкой, факел между мобами, пропавшая рука.

Полный прогон — 22 набора в `tests/`, список в `AGENTS.md`. Все зелёные.

⚠️ После любого батча арта — `godot --headless --import`, иначе файлы лежат на
диске, но игра их не видит. Горели на этом дважды.
