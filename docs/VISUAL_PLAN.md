## 1. Эффекты боя — самое большое отставание

### 1.1 Вспышка попадания (кадр 15.0 с)

**У них:** силуэт врага заливается **чистым белым целиком**, вокруг мягкое
свечение-блум, под ногами **розовое кольцо на земле**, вверх летят розовые
ромбики-частицы.

**У нас:** `spr.modulate = Color(3.2, 2.5, 2.3)` — это осветление, цвета
остаются. Читается как «моб посветлел», а не «попал».

**Что делать:** заливка силуэта белым. Технически — шейдер на спрайте врага с
uniform `flash` (0..1), смешивающий цвет к белому, сохраняя альфу. У нас уже
есть `sprite_outline.gdshader` на этих спрайтах — добавить второй проход или
uniform в него. **Кольцо на земле** — отдельный квад на полу, как контактная
тень, только светящийся.

### 1.2 Цифры урона (кадр 5.5 с)

**У них:** урон — **огромное белое число, ~100 px высотой**, жирное, с тонкой
обводкой. Над ним **название механики капсом**: `OVERKILL`, `PRECISE CUT`.
Стоит по центру над врагом, не сбоку.

**У нас:** `_spawn_popup` рисует размером 21–28 px где-то над головой. При
крите добавляется «КРИТ!» мелким.

**Что делать:** поднять базовый размер до **64 px**, крит и перебор — до 96.
Название механики отдельной строкой сверху, капсом, мелко: `ПЕРЕБОР`,
`ПРОБОЙ`, `КРИТ`. Это тот же код `_popups`, только другие числа и вторая строка.

### 1.3 Луч в точке удара (кадр 5.5 с)

**У них:** вертикальный белый **световой столб** в точке попадания, узкий,
быстро гаснет. Плюс белый всплеск-звёздочка.

**У нас:** `_spawn_impact` рисует круг и лучи из центра.

**Что делать:** добавить вертикальный столб к существующему `_draw_impacts` —
это две линии с градиентом альфы, дешево.

### 1.4 Линия прицеливания (кадр 12.0 с)

**У них:** **толстая сужающаяся лента**, широкая у карты и сходящаяся к цели,
градиент кремовый → зелёный. Не пунктир, не шарики.

**У нас:** линия из шариков.

**Что делать:** заменить на полигон-ленту: `draw_polygon` по кривой с
уменьшающейся шириной. Кривая уже считается, меняется только отрисовка.

### 1.5 Объявления срабатываний (кадр 16.0 с)

**У них:** сработала реликвия — сверху жёлтым капсом:
`OVERHEAT +2 STR`, строкой ниже `+3 BURNING FRAGMENTS`.

**У нас:** уходит в лог мелким текстом внизу, никто не читает.

**Что делать:** баннер сверху по центру на 1.2 с, жёлтый, капсом. Событий у нас
уже хватает (`status_applied`, реликвии, кости) — просто некуда выводить.

### 1.6 AoE-эффект (кадр 16.0 с)

**У них:** огонь **заливает пол-экрана**, полупрозрачный, с искрами.

**У нас:** у площадных карт (`SWEEP`) нет вообще ничего своего.

## 2. Интерфейс — где мы выглядим отладкой

### 2.1 Строка героя — главная проблема

**У нас** это буквально одна строка текста:

```
⚡ 3/3    🛡 0    🦴 0    ❤ 56/56
```

**У них** каждое значение — отдельный элемент:

| Что | Как выглядит у них |
|---|---|
| Энергия | **зелёная пилюля**, из левого края торчит жёлтая молния, `2/3` белым жирным с обводкой |
| Баффы игрока | тёмные скруглённые квадратики с иконкой + число, столбиком над энергией |
| HP | в левой панели: сердечко + полоска-пилюля, `55/88` мелким белым внутри |

Это дёшево сделать и разница будет самой заметной из всего списка.

### 2.2 Полоски HP врагов и статусы (то, на что вы показали)

**У них** (увеличенная вырезка):

- имя врага — **белым, без обводки**, гуманистический серифный шрифт, мелко
- полоска — **пилюля лососевого цвета**, БЕЗ чёрного контура, число белым внутри
- броня — **иконка-щит формой щита**, наезжает на левый край полоски
- статусы — **круглые иконки под полоской**, число не показывается когда 1

**У нас:** полоска с чёрной обводкой, броня синей пилюлей, статусы —
прямоугольные плашки с числом рядом.

**Нужен арт**, промпты в §5.

### 2.3 Намерение врага

**У них:** иконка меча + `3x2` **оранжевым, крупно** (~28 px), поднято высоко и
**смещено в сторону** от головы, а не по центру.

**У нас:** `🗡 3×2` размером 21 по центру над головой — теряется на фоне скалы.

### 2.4 Счётчики колоды

**У них:** **веер из трёх карт** рубашкой вверх, с круглым бейджем-числом в
углу. Слева колода, справа сброс.

**У нас:** плоские прямоугольники с подписью.

### 2.5 Левая панель

**У них:** дерево с текстурой, скруглённые углы, портрет в **круглой деревянной
раме**, миникарта — сетка бежевых квадратов с иконками (сундук, черепа),
пройденный путь светлее. Три слота еды прямоугольниками с иконками.

**У нас:** близко по структуре, но плоские цвета вместо текстуры дерева.

## 3. Мир и уровень

### 3.1 Стены

**У них:** нарисованный **кирпич** с сильной перспективой, видимый потолок
аркой, кирпичи разного оттенка. Читается как рисунок.

**У нас:** процедурная скала с рельефом. Технически сложнее, выглядит
**шумнее** — из-за детализации на каждый пиксель нет чистых форм.

Это не «переделать всё»: можно **уменьшить силу микрорельефа** и увеличить
масштаб рисунка камня, чтобы формы читались крупнее.

### 3.2 Декор — вот чего у нас нет совсем

В их коридорах на кадрах: **красные знамёна с черепом**, бочки, решётки,
плющ по стенам, кучи щебня, грозди грибов на стенах, кристаллы,
каменные колонны, надгробия, светящиеся розовые столбы света.

**У нас** в коридоре только факелы. Каждый коридор выглядит одинаково.

Это самая дешёвая по коду и самая заметная правка: у нас уже есть система
пропов (`ForestProps`, `forage_sprites`), нужен только арт.

### 3.3 Пол

**У них:** крупная брусчатка с **разноцветными камнями** (розовые, серые).
**У нас:** однородная скала.

## 4. Шрифты

**У них два шрифта, и оба не декоративные:**

- **тёплый гуманистический сериф** для имён, названий карт, подписей —
  спокойный, читается мелко
- **жирный округлый без засечек** для ЧИСЕЛ — с обводкой, очень контрастный

**У нас:** `Ruslan Display` (декоративный старославянский) + `Forum`.

Проблема: **Ruslan Display слишком декоративен для интерфейса**, а числа
рисуются тем же `Forum` — тонким и невыразительным. У конкурента числа
намеренно другого шрифта, жирнее всего остального.

**Предложение:**

| Роль | Сейчас | Предлагаю |
|---|---|---|
| Заголовки, название игры | Ruslan Display | **оставить** — это наше лицо |
| Имена, карты, подписи | Forum | **PT Serif** или **Alegreya** — тёплый сериф с полной кириллицей |
| **Числа** (урон, HP, энергия) | Forum | **Rubik ExtraBold** или **Nunito ExtraBold** — округлый жирный |

⚠️ Перед подключением **обязательно проверить кириллицу разбором cmap**, как
делали с Cinzel и MedievalSharp — они оба показали **0 из 64 глифов**, и это
выяснилось только замером. Все четыре предложенных заявлены с кириллицей и под
OFL, но заявление — не проверка.

## 5. Что нарисовать (батч 13)

Правила §3.12: квадрат 1:1, магента `#FF00FF`, читаемость в мелком размере.

### 5.1 Полоски и рамки HP — ✅ ПОДКЛЮЧЕНО

Трёхчастная отрисовка (`_bar3`): крайние скругления + растянутая середина.
Скругления **замерены по арту**, а не назначены: 112 px на подложке и 76 px на
заливке из 1024. С неверной шириной шапки скругление либо сплющивается, либо
повторяется в середине, а полоска на 8% здоровья превращается в одну кляксу.

### 5.1a Исходные требования (для справки)

⚠️ Эти **не квадратные** — нужны широкие полосы, которые движок растянет по
ширине (nine-patch). Просить **соотношение 8:1**, без скруглений на концах
(движок скруглит сам) — либо со скруглениями, но тогда фиксированной длины.
